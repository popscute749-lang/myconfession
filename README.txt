MY CONFESSION WEBSITE

1. Extract this ZIP file.
2. Keep index.html and the images folder together.
3. Open index.html in a browser to preview.

To publish it free with GitHub Pages:
- Create/sign in to a GitHub account.
- Create a new public repository.
- Upload index.html and the images folder (including all 3 JPGs).
- In the repository, open Settings > Pages.
- Under Build and deployment, choose Deploy from a branch.
- Select main and / (root), then Save.
- GitHub will provide your public website URL when deployment finishes.

Do not rename or separate the image files unless you also update their paths in index.html.
